# Finance Tracker Pro: Telegram Bot & Mini App

A comprehensive finance tracking solution featuring a professional Telegram Bot and a Feature-Rich Web Mini App.

## Features
- **Telegram Bot:** Quick transaction entry, category management, and automated Excel reports.
- **Web Mini App:** Advanced dashboard with Chart.js visualizations, detailed monitoring, and full transaction CRUD (Edit/Delete).
- **Multi-Currency Support:** Real-time exchange rate conversion for accurate financial overviews.
- **Localization:** Full support for Uzbek, English, and Russian.
- **Payment Methods:** Track expenses and income by Cash or Card.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Configure `.env` with your `BOT_TOKEN` and `DATABASE_URL`.
3. Initialize the database using `database/create_tables.sql`.
4. Run the application: `python main.py`.
